Sou desenvolvedor backend em Salvador, Bahia. Construo APIs e integrações para conectar o que acontece na tela ao trabalho de quem está do outro lado. Tenho interesse especial em automação de atendimento e IA aplicada a produtos.

## Projetos em desenvolvimento

- **RevGás** — Integro o atendimento pelo WhatsApp ao ERP de uma revenda de gás. Os fluxos no n8n se comunicam com uma API em Python e FastAPI para organizar as informações de cada pedido.
- **Escuta** — Desenvolvo uma plataforma para pacientes encontrarem terapeutas, agendarem sessões e entrarem em videochamadas. O aplicativo usa Flutter, com API em NestJS e dados em PostgreSQL. A integração de vídeo com LiveKit já passou por testes.
